# 「班阵」产品需求文档

## 1. 产品定义

班阵是面向中国高中教师的 Windows 本地排座应用。页面仅保留精简的排座工作区，教师可从左侧待入座名单导入学生，并在同一工作区完成布局调整、规则设置、方案生成和导出。

首次进入工作台或新建班级后，必须先在覆盖画布区域的毛玻璃选择层中确认桌型、行列或固定模板，再生成初始座位。初始布局确认前不可跳过或关闭选择层。
用户可以为当前桌型、行列和护法座组合命名并保存为本机自定义模板；自定义模板可在初始布局和后续布局调整中选择、覆盖同名项或删除。

首个交付里程碑是可交互视觉原型。真实数据库、求解器、文件读写、离线授权和 Windows 安装包在视觉确认后接入。

每次进入应用先弹出免责声明，右上角同时始终提供显著入口。弹窗覆盖本地数据、AI 数据流、未成年人个人信息、公平使用、人工复核、维护计划和责任边界，并记录使用者确认的说明版本与时间。

## 2. 四步流程

1. 名单：支持上传至少两列的任意列结构 Excel 或 CSV，也可手动添加。文件读取后进入可编辑预览页，由教师确认必填的姓名和学号列，可继续映射性别、班级、成绩、身高和标签，并可修改单元格或删除整行后再导入。多个标签支持使用顿号、逗号或分号分隔；标准模板列自动匹配。缺少性别时允许导入，但防早恋模式置灰并提示用模板补充学生信息。
2. 布局：不显示学生名单侧栏；选择 48 座四组、54 座三组、60 座五组、考试单列、双人桌或空白布局后，教室画布立即同步，并可在侧栏调整网格与走廊，在画布底部工具栏调整讲台、空位和禁用座位。
3. 排座：从名单或座位图多选学生，创建不坐同桌、指定同桌、指定相邻和指定不相邻规则；在同一页面选择本地算法、检查字段覆盖率和硬约束，每次生成一个方案，不满意可再次生成。有规则的学生显示可点击的深色“规”标记，可查看其参与的全部规则；自动重排和方案预览后仍可拖动学生微调。
4. 导出：在独立设置页预览并输出 Excel、PNG 或 PDF；PNG 与 PDF 可选择普通版或精简版。

## 3. 布局不变量

- 一个教室只能存在一个讲台，自动位于所有大组上方中央。
- 教室门可设为左前、右前、左后或右后，画布与打印预览使用同一位置数据。
- 地点大组整体居中，内部宽度可不同，但相邻大组之间的走廊必须等宽。
- 禁用座位使用珊瑚红粗叉与浅红底显著标识，不参与拖拽入座或自动排座。
- 讲台左右护法是具有特殊标记的普通座位，不创建额外讲桌。
- 地点大组不自动建立学生小组；两者分别管理。

## 4. 自定义规则语义

- 四类关系均为硬约束。
- 两人选择直接生成一条关系。
- 三人以上选择“不坐同桌”或“指定不相邻”时，对所有学生两两展开，规则数为 `n(n-1)/2`。
- 三人以上选择“指定同桌”或“指定相邻”时进入配对面板；本批每人只能出现一次，奇数人数不能确认。
- 相邻包括同桌、前后左右和四个斜角；走廊、空位或不同地点大组会阻断邻接。
- 同一学生对的互斥规则必须在保存前诊断，并显示涉及学生和修改建议。

## 5. 后续功能阶段

- SQLCipher 本地存储、Windows Credential Manager 密钥保护和离线签名授权。
- 十一种本地排座算法、单方案重复生成、固定种子复现、不可满足诊断。
- `.seats` 加密快照和 Excel 座位表导入。
- v1.1 增加 OpenAI 兼容接口，由 AI 生成匿名化结构规则，本地求解器执行。
- AI 座位方案仅供参考，最终座位由老师人工确认。
- BSCE 导入通过独立适配器后续接入。

## 6. 可选皮肤

- 默认皮肤保持暖白纸张与炭黑简笔线稿。
- 可爱款采用奶油暖白、樱花粉和少量薄荷绿，使用猫耳切角、猫爪、鱼骨和毛线球等克制纹样。
- 可爱款教室画布底层使用超大淡粉猫爪平面水印，边缘保持清晰，不使用模糊或毛玻璃效果；透明度必须足够低，不能影响姓名、座位和规则关系的可读性。
- 右上角提供“简约 / 猫爪”即时主题切换；选择保存在本机，Canvas 与 DOM 控件同步换色。
- 主题切换包含 160–420ms 的按钮按压、猫爪回弹和清晰水印淡入动效，并服从“降低动态效果”设置。
- 纯净打印模式仍需提供无装饰或低装饰版本，避免皮肤增加打印墨耗。
