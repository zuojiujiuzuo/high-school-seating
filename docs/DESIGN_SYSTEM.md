# 班阵视觉系统

## 设计方向

界面来自教师熟悉的纸质座次表、铅笔标记和教室方格纸，但不模拟真实纸张纹理。游戏质感来自选择、拖拽、换位和生成过程，而不是深色皮肤或夸张装饰。

## 令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 暖白纸面 | `#F8F5ED` | 画布和应用背景 |
| 明亮纸面 | `#FFFDF8` | 面板、卡片、学生姓名签 |
| 炭黑墨线 | `#242521` | 主文字、桌椅线条 |
| 钴蓝批注 | `#2F6FED` | 选择、主操作、动效路径 |
| 绿色确认 | `#4D9C6B` | 满足规则、保存完成 |
| 珊瑚红警示 | `#EF6A5B` | 冲突、缺失和不可满足 |

- 品牌字：系统楷体，仅用于“班阵”字标。
- 界面字：Segoe UI、Microsoft YaHei、PingFang SC 回退链。
- 数据字：DIN Alternate 或系统等宽字体。
- 控件圆角以 7–12px 为限，不使用大胶囊形状。
- 阴影只用于模态窗口、候选方案条和浮层；常规信息依靠边框与留白分组。

## 标志性交互

- 框选时使用蓝色虚线与编号角标，静态截图也能表达选择关系。
- 换位时两个姓名签沿相反弧线交叉，260ms 内完成并以轻微缩放落座。
- 自动排座按大组和排数形成波浪动画，允许降低动态效果。
- 纯净视图隐藏所有工具，只保留可直接截图的暖白座位图。

## 可爱款皮肤（已确认）

- 主色从钴蓝切换为樱花粉/莓果粉，成功态继续使用低饱和薄荷绿。
- 中央画布底层增加低透明度的超大淡粉猫爪平面水印；不使用模糊或毛玻璃滤镜，并始终位于学生姓名签和布局线条下方。
- 猫爪、鱼骨和毛线球只用于空白边角；不使用遮挡操作区的人物或悬浮吉祥物。
- 禁用座位继续使用粗叉和“禁用”文字，不能只依赖颜色表达状态。
- 右上角主题控件提供真实即时切换并记忆选择；主题切换时 Canvas 重新绘制粉色操作反馈，背景猫爪柔和淡入。
